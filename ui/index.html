What Each Field Means
Scenario — Pre-loaded demo cases. Each tests a different system behavior (clean diagnosis, contradictory evidence, sparse data, security filtering).
Store — The retail store to investigate. Dataset has 45 stores. Each store maps to a region (North/South/East/West).
Dept — Optional. Narrow investigation to a specific department within the store (81 depts). Leave empty to investigate store-level.
Date — The specific week to analyze. The system looks at the KPI movement for that week vs. historical baseline. Leave empty for latest.

Pipeline Steps
Hypotheses
Competing explanations the system evaluated. Each scores evidence support vs. contradiction. Winner = highest net score. Refuted = contradicting evidence found.
Confidence
How trustworthy the diagnosis is. Three independent signals are weighted into an overall score. Tiers: HIGH (>=0.75), MEDIUM (>=0.5), LOW (>=0.3), ABSTAIN (<0.3).
Recommendation
Structured action derived from the winning hypothesis. Only generated when confidence is HIGH or MEDIUM. Includes owner and monitoring plan.
Narratives
Same facts, framed for different audiences. Store Manager = operational, action-first. Regional VP = strategic, business-impact framed. Source shows "llm" or "template".
